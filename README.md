- 📱 Cross-platform mobile development with React Native, TypeScript and modern React
- 🧩 State management and data fetching with Redux and RTK Query
- ⚙️ Backend services with Node.js, deployed on AWS and Azure
- 🔐 Strong focus on **mobile application security**
